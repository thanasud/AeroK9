# XL430 reference CAD

`XL430-W250-T_New_ROBOTIS.stp` is the official **XL430-W250 (New)** STEP
model linked from the ROBOTIS e-Manual drawing section.

- Product: DYNAMIXEL XL430-W250-T, new case released in 2018
- ROBOTIS download record: `https://www.robotis.com/service/download.php?no=773`
- Downloaded: 2026-08-22
- Native STEP bounding box: 28.5 x 46.5 x 40.9 mm including shaft/idler
- Nominal case dimensions: 28.5 x 46.5 x 34 mm

The STEP is embedded into `PipeRobotV2_XL430_RealMotor.FCStd`; it is also
used directly for automated interference and screw-axis checks in
`build_xl430_swingarm_mount.py`.
